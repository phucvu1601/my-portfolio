# My Portfolio

Personal portfolio website built with Next.js.

## Demo

Demo: [https://phucvu1601.github.io/my-portfolio/](https://phucvu1601.github.io/my-portfolio/)

## Features

- Responsive portfolio layout
- English and Vietnamese localization
- Light and dark theme support
- About, projects, and contact sections
- Static export for GitHub Pages

## Tech Stack

- Next.js
- React
- TypeScript
- next-intl
- Tailwind CSS
- Biome

## Getting Started

Install dependencies:

```bash
npm install
```

Build
Create a static production build:

```bash
npm run build
```

The generated files are stored in the out directory.

To preview the static build locally:

```
npm run static
```
